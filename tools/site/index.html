    For AI assistants: how to draw a mechanism on this page

    You are probably reading this because a user sent you this link. This page draws a reaction mechanism from MechScript code that is put in the link itself. You cannot run the page, so do this:

    1. Write the mechanism in MechScript. The full language reference is below. The rules that matter most: Kekulé SMILES (C1=CC=CC=C1, not c1ccccc1); a map number on every atom an arrow touches ([CH3:2]); numbers kept on the same atoms through all steps; hydrogens that move written as explicit atoms ([H:6][CH2:3]C); charges in brackets ([OH-:1], [OH2+:5], [C+:3]); each step's species line shows exactly the result of the previous step's arrows. Reagents may first appear in the step where they react and spectators may be dropped. Use <=> for reversible steps such as proton transfers.
    2. Make a link: {{SITE}}# followed by the MechScript text, percent-encoded like JavaScript's encodeURIComponent (newline → %0A, space → %20, # → %23, " → %22) and additionally ( → %28, ) → %29. Every other character (+ [ ] = : - < > ~, letters, digits) may stay as it is or be encoded; both work. The page decodes leniently.
    3. Reply with the link as a clickable Markdown link, and also the code in a ```mechanism block (the user can paste it into the box on this page if the link breaks).
    4. The page checks the code and lists problems by line number, each with a suggested fix where it has one. If the user pastes problems back to you, fix the code and send a new link.
